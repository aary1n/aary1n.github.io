# aaryans.page

Plain HTML/CSS/JS, generated by one Python script.

```
pip install -r requirements.txt
python build.py --serve      # rebuilds docs/ and serves it at http://localhost:8000
```

Commit `docs/` along with your changes. GitHub Pages serves `main` → `/docs`.

## Writing

| To change | Edit |
|---|---|
| The landing page | `content/about.md` |
| A blog post | `content/posts/YYYY-MM-DD-slug.md` (new file = new post) |
| Blog legend categories, name, top-right links | `content/site.toml` |
| The line above the flower grid | `content/flowers.md` |
| Photo names and alt text | `data/photos.json` |
| Look | `static/css/site.css` (night and paper colours at the top) |

A post starts with a settings block, then plain Markdown:

```
+++
title = "Something I noticed"
date = 2026-11-02
category = "essay"      # one of the keys in site.toml
draft = true            # optional: leaves it out of the build
photo = "0042"          # optional: flower on the share card (default: the one photographed closest to the post's date)
description = "..."     # optional: blurb under shared links (default: the first paragraph)
+++

First paragraph...
```

The URL is the filename without the date: `/blog/slug/`.

Every build also draws a share card for each post and page into `docs/og/` (see `cards.py`):
the image X, LinkedIn or iMessage shows when someone shares the link.
Anything written `[PLACEHOLDER ...]` shows up underlined in ochre until you replace it.

## Adding photos

1. Copy original JPEGs into `raw/` (never committed). Download originals so the capture date survives;
   photos sent through messaging apps usually lose it.
2. `python tools/process_photos.py`: makes the thumbnail and medium WebP for each new photo with **all**
   metadata removed (GPS included), and adds it to `data/photos.json` with its capture date.
   Photos already processed are skipped, so it's safe to rerun.
3. Optionally fill in `flower` and `alt` for each entry in `data/photos.json`, then `python build.py`.

## Layout

```
build.py              content + data -> docs/
cards.py              share-card images, used by build.py
content/              site.toml, about.md, flowers.md, posts/*.md
data/photos.json      one entry per photo
static/               css, js, butterfly drawings -> docs/assets/
tools/                image scripts
docs/                 the built site (img/ and CNAME are never touched by the build)
raw/                  your original photos; gitignored, never committed
```
